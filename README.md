## 🚀 О проекте

**NEON VOID** — это аркадная игра в жанре "space shooter", написанная на чистом JavaScript без использования сторонних движков (вроде Phaser или Three.js). Игра демонстрирует продвинутые навыки работы с математикой движения, коллизиями и процедурной генерацией звука.

В отличие от других моих проектов (*Neon Strike* и *Neon Defense*), здесь упор сделан на **физику инерции** и **динамическую сложность**. Чем дольше ты живешь, тем агрессивнее становятся враги.

### ✨ Ключевые особенности

- 🛸 **Физика полета**: Реалистичная инерция корабля. Ты не останавливаешься мгновенно, нужно планировать маневры заранее.
- 💥 **Разрушаемые объекты**: Крупные астероиды разбиваются на более мелкие фрагменты при попадании, создавая цепные реакции.
- 👾 **3 типа врагов**:
  - 🪨 **Астероиды**: Медленные, но опасные из-за размера.
  - 🤖 **Дроны**: Летают зигзагами, пытаясь таранить игрока.
  - 🔴 **Охотники**: Агрессивно преследуют цель, набирая скорость.
- 🔊 **Процедурный звук**: Все звуки (выстрелы, взрывы, двигатели) генерируются в реальном времени через Web Audio API. Никаких MP3 файлов!
-  **Бесконечная прогрессия**: Сложность растет экспоненциально со временем. Нет финального уровня — есть только твой рекорд.

## 🕹 Управление

| Клавиша / Действие | Результат |
|--------------------|-----------|
| `W` `A` `S` `D`    | Движение корабля (с учетом инерции) |
| `↑` `↓` `←` `→`    | Альтернативное управление движением |
| **Мышь**           | Прицеливание (корабль поворачивается к курсору) |
| **ЛКМ**            | Стрельба |

💡 **Совет:** Не стой на месте! Используй инерцию для резких уклонений ("drifting").

## 🛠 Технологии

- **HTML5 Canvas API** — рендеринг графики 60 FPS.
- **Vanilla JavaScript (ES6+)** — логика игры, классы, векторная математика.
- **Web Audio API** — синтез звуковых эффектов осцилляторами и шумом.
- **CSS3** — адаптивный интерфейс и неоновые эффекты свечения.
